Step 1: RELOAD THE EXTENSION
  1. Go to: chrome://extensions/
  2. Find "IRCTC Tatkal Agent"
  3. Click the 🔄 RELOAD button
  4. Wait 2 seconds

Step 2: HARD REFRESH IRCTC TAB
  1. Go to IRCTC tab
  2. Press: Ctrl + Shift + R (hard refresh)
  3. Wait for page to load

Step 3: OPEN DEBUGGING CONSOLE
  A. Background Service Worker Console:
     - Go to chrome://extensions/
     - Click on "Service Worker" under agent
     - DevTools opens (keep this open)
  
  B. IRCTC Tab Console:
     - Go to IRCTC tab
     - Press F12
     - Go to "Console" tab
     - (keep this open too)

Step 4: TRIGGER BOOKING AGAIN
  1. Click "Manual Trigger Booking" in popup
  2. Look at BOTH consoles
  3. Watch for logs starting with [CONTENT] or [BG]

Step 5: SHARE THE LOGS
  Look for where logs STOP
  - If you see [CONTENT] but not [BG] → Different issue
  - If you see [BG] but booking times out → API issue
  - If you see both but hanging → Message response issue
