🔧 HOW TO CUSTOMIZE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CHANGE PRIMARY COLOR:
  File: popup.css
  Find: --primary: #6366f1;
  Replace #6366f1 with your color (e.g., #FF5733)
  Result: All primary-colored elements change instantly

CHANGE ANIMATION SPEED:
  File: popup.css
  Find: all 0.3s cubic-bezier(...)
  Change 0.3s to faster (0.2s) or slower (0.5s)
  Result: All animations speed up or slow down uniformly

REDUCE GLOW INTENSITY:
  File: popup.css (and popup-premium.css)
  Find: rgba(99, 102, 241, 0.3) [or other color]
  Change 0.3 to:
    └─ 0.1 (very subtle)
    └─ 0.5 (very intense)
  Result: Glow effect becomes stronger or weaker

MAKE CORNERS MORE ROUNDED:
  File: popup.css
  Find: border-radius: 12px;
  Change 12px to:
    └─ 8px (less rounded, modern)
    └─ 20px (more rounded, soft)
  Result: Corner roundness changes throughout

CHANGE BLUR STRENGTH:
  File: popup.css
  Find: backdrop-filter: blur(20px);
  Change 20px to:
    └─ 10px (subtle blur)
    └─ 30px (strong blur)
  Result: Glassmorphism effect becomes stronger/weaker

ADJUST SHADOW DEPTH:
  File: popup.css
  Find: box-shadow: 0 0 20px rgba(...);
  Change values for different shadow styles
  Result: Shadow system becomes lighter/heavier
